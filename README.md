# Билпрайм: приложения автосервиса

Три приложения из одного кода: Volvo (bilprime.ru), Mercedes (bpmers.ru), Geely (bilgeely.ru).
Марка задаётся в `www/brand.js`. Для просмотра в браузере: `www/index.html?brand=volvo&demo=1`.

Пока не подключено: история ремонтов из 1С, отправка заявок, SMS-вход, пуш-уведомления.
